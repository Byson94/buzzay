# Input Keyboard Options

All the keyboard options in `[input.keyboard]`.

## layout

Keyboard layout option like "us", "fr", "de".

```toml
[input.keyboard]
layout = "us"
```

## variant

Keyboard variant option.

```toml
[input.keyboard]
variant = "altgr-intl"
```

## options

Keyboard options like remapings.

```toml
[input.keyboard]
# map caps lock to escape
options = "caps:escape" 
```
