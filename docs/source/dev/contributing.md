# Contributing

Contributing to buzzay is a great way to help the project grow and we really appreciate your help.

## Forms of Contribution

All forms of contribution are aprreciated. Whether that be fixing a typo in any document 
or introducing new features to the core compositor. You can do what you believe suits
the best for you.

## Coding Style

If you are doing code contributions, then do keep these coding styles in mind. It is not
strictly followed, but ensuring it matches the rest of the codebase is appreciated.

- Use **tab** for indentation.
- `*` belongs to the variable name. Example: `void *var;`
- Prefer local variables over globals.

That's pretty much the only rules.
