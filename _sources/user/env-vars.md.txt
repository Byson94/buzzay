# Env Variables

List of all the environment variables buzzay is aware of by default.

- `BUZZAY_CONF` Direct path to configuration file to load.
- `XDG_CONFIG_HOME` Optionally used to locate configuration file.
- `XCURSOR_THEME` Used to apply custom cursor theme. (overridden with `env.xcursor-theme`)
- `XCURSOR_SIZE` Used to apply custom cursor size. (overridden with `env.xcursor-size`)
